# 公允价值算法 v4 — 归一化 + 角色拆分 + CAPM 对齐行业惯例

> v2（多年归一化）解决了「单季度输入污染全部模型」；v3 解决了「把估值和下限混在一起加权」。两者叠加。

> 适用范围：`frontend/src/lib/data/` 下的估值管线，即网页 Dashboard 与告警（Alerts）共用的同一套算法。

## 1. 问题定位

### 1.1 触发场景

用户报告的页面输出（用户提供，本次会话**未能**连线行情源复核，见 §6）：

| 字段 | 页面值 |
|---|---|
| 现价 | $648.03 |
| 分析师目标均值 | $758.28 |
| 分析师目标区间 | $580.00 – $1000.00 |
| Forward P/E | 18.5 |
| PEG | 0.86 |
| DCF 公允价值 | **$133.95** |
| 偏离度 | **+383.8%** |

同一标的在第三方（Morningstar，用户提供）的 Fair Value 为 $850。

### 1.2 内部矛盾

公允价值 $133.95 意味着该股票以 **约 4.8 倍**于其内在价值交易。但同一份数据里 Forward P/E 18.5、PEG 0.86——这两个数字描述的是一家**估值温和的成长股**。一套自洽的估值体系不会同时输出这两种结论。所以 $133.95 不是"保守"，是**算法错误**。

### 1.3 根因（旧代码）

旧管线的全部模型都由 3 个标量驱动，且这 3 个标量都取自**最近 12 个月的快照**：

| 标量 | 旧来源 | 失效方式 |
|---|---|---|
| `freeCashflow` | `financialData.freeCashflow`（TTM） | FCF = 经营现金流 − 资本开支。公司把资本开支翻倍去建数据中心时，经营现金流照样增长，FCF 却塌陷。永续模型把这个**低谷值资本化到永远** |
| `eps` | `defaultKeyStatistics.trailingEps` | 一次性费用（诉讼和解、一次性税费、减值）压低 TTM EPS，Graham Number / Graham 公式 / Lynch / EPV **四个模型同时**被拉低 |
| `earningsGrowthRate` | `financialData.earningsGrowth`（最近一期同比） | 同一笔一次性费用让单季同比变成深度负值，被 clamp 到 −10% 后**复利十年** |

因为所有模型共用这 3 个被污染的输入，"多模型平均"提供不了任何分散化——它们是一起错的。

三个次级放大器：

1. **权重结构**：核心两阶段 DCF 占 50%，剩余 50% 由其余模型**均分**——包括 Graham Number（1930 年代防御型选股的筛选线）和 EPV（零增长假设）。这两个天然的"下限指标"因此拿到了与现金流模型同量级的权重。
2. **离群值过滤器失效开放（fail-open）**：过滤器锚定在分析师目标区间上；一旦所有模型值都被判定为不可靠，代码回退到「对**全部**值取平均」——包括刚刚被判定不可靠的那些。守门员在最需要他的时刻离场。
3. **固定折现率**：所有股票一律 10% 折现率 / 2.5% 永续增长，与该企业现金流的历史稳定性无关。

## 3. 归一化规则

### 3.1 自由现金流

取以下 4 个候选值的**中位数**：

| 候选 | 计算 | 作用 |
|---|---|---|
| TTM 实际 FCF | 直接取值 | 锚定现实 |
| 全周期利润率 | `median(FCF/营收, 最多8年) × TTM营收` | 熨平投资周期 |
| 近期利润率 | `median(FCF/营收, 近3年) × TTM营收` | 反映当前经营状态 |
| 股东盈余 | `TTM经营现金流 − 维持性资本开支` | 剔除扩张性投资 |

**维持性资本开支** = `min(TTM实际资本开支, max(折旧摊销按营收缩放, 历史资本开支强度中位数 × TTM营收))`

逻辑链条（为什么 A 导致 B）：扩张性资本开支买的是**未来**的盈利能力；把它从**今天**的现金流里全额扣除、再把扣除后的结果按永续增长资本化，等于对同一笔支出收费两次。所以维持性口径才是永续模型该用的分子。`min()` 保证模型永远不会假设维持性开支**高于**公司实际花掉的钱。

**护栏**：
- 归一化 FCF ≤ TTM 经营现金流（算术上限）
- TTM FCF > 0 时，归一化值被限制在 `[0.75×, 2.5×]` TTM FCF 区间内

### 3.2 制度转换守卫（Regime Guard）——最关键的一条

把当期被压低的利润率替换成多年中位数，在"这是周期/投资期"时是**对的**，在"这家公司就是在变差"时是**错的**。

判定规则：比较**近 3 年**与**前半段**的利润率中位数。

| 判定 | 条件 | 处理 |
|---|---|---|
| 持续下行 | 近3年 < 前半段 × 0.8 | **丢弃**全周期中位数候选，只用近期水平平滑 |
| 持续上行 | 近3年 > 前半段 × 1.25 | 同样丢弃全周期中位数（避免把改善中的公司往下拉） |
| 稳定 | 其余 | 使用全周期中位数 |

**资本开支高峰会抑制"持续下行"判定**——因为此时 FCF 利润率压缩的原因是投资决策，不是经营恶化。这正是区分「META 式资本开支周期」与「真实基本面衰退」的那条线。

### 3.3 每股收益

候选中位数：TTM EPS、`Yahoo trailing normalizedIncome / 股数`、`中位数净利率 × TTM营收 / 股数`。

`normalizedIncome` 是 Yahoo 已剔除一次性损益的口径——这直接对应 §1.3 表格的第二行。护栏：`[0.7×, 2.0×]` TTM EPS。同样受 §3.2 制度守卫约束。

### 3.4 增长率

**一个来源一票，取中位数**：

1. 营收 CAGR（最多 5 年，端点做两期平滑）
2. 归一化净利润 CAGR
3. 自由现金流 CAGR
4. 分析师长期（+5y）增速预期
5. 最近一期盈利同比
6. 最近一期营收同比

CAGR 仅在首尾两端**均为正**时计算（跨越符号变化的 CAGR 在算术上无意义）。端点采用两期平均，避免某一个特别强/弱的起始年份决定整条趋势线。

最终限制在 `[-5%, +25%]`。只有单一来源时打 7 折（缺乏交叉验证）。

具体例子：一笔一次性税费让"最近一期盈利同比"变成 −42%。旧算法直接把 −42% 拿去 clamp 成 −10% 再复利十年。新算法里它只是 6 票中的 1 票，中位数落在其余 5 个来源上，不受影响。

### 3.5 折现率（随波动率浮动）

```
折现率 = 9% + clamp(波动率, 0, 1) × 4%  [+ Beta 调整] [+ 数据不足加价]
波动率 = max(FCF利润率变异系数, 净利率变异系数)   // 变异系数 = 标准差/|均值|
限制区间 [8.5%, 13%]
```

为什么波动率该进折现率：折现率是**要求回报率**。一家利润率年年波动 ±50% 的企业，其未来现金流的预测误差远大于一家波动 ±5% 的企业；承担更大的预测误差就应当要求更高的回报。变异系数是无量纲的，所以 25% 利润率的软件公司和 3% 利润率的零售商可以直接比较。

永续增长率：默认 2.5%；波动率 > 0.6 降至 2.0%；归一化增长率 ≤ 0 降至 1.5%。

## 4. 模型权重重构

权重反映的是**"该模型对持续经营企业价值的证据强度"**，不是"该模型有多保守"。

| 模型 | 新权重 | 旧权重（约） |
|---|---|---|
| 两阶段 DCF（归一化） | **26%** | 50% |
| 10年 FCF DCF（增长衰减） | 13% | ~5.6% |
| 保守 FCF DCF（下行情景） | 10% | ~5.6% |
| 第三方 DCF（FMP，全部共享） | 10% | ~5.6% × N |
| EV/EBITDA | 9% | ~5.6% |
| 剩余收益模型 RIM | 8% | ~5.6% |
| 5年 FCF DCF | 8% | ~5.6% |
| 盈利能力价值 EPV | 7% | ~5.6% |
| 格雷厄姆内在价值公式 | 5% | ~5.6% |
| 股息折现 DDM | 5% | ~5.6% |
| Lynch (PEG=1) | **2%** | ~5.6% |
| 格雷厄姆数字 | **2%** | ~5.6% |

两处关键调整：

- **格雷厄姆数字 5.6% → 2%**。它是 1930 年代为防御型投资者设计的**筛选阈值**（"低于此价才值得看"），不是估值模型。对轻资产企业它天然给出极低的值。让它以接近现金流模型的权重参与平均，等于系统性地把公允价值往下限拽。
- **第三方 DCF 合并为一个 10% 桶**。FMP 会返回 4 个高度相关的 DCF 值；按原逻辑它们各自独立计权，合计可达 22%，一个数据源就能压过全部内部模型。

模型结构本身也改了两处：
- 两阶段 DCF 从「10 年平增长 + 断崖式跌到 2.5%」改为「5 年增长 + 5 年线性衰减至永续」。断崖恰好落在价值最集中的位置。
- 剩余收益模型的超额收益（ROE − r）改为 8 年线性衰减，而非"5 年恒定后归零"。超额回报会吸引竞争，这是衰减的经济学理由。

净现金桥：Yahoo/FMP 的 FCF 是**杠杆后**口径（经营现金流已扣利息），所以折现结果本身就是股权价值，**不再扣减债务**；但净现金是现金流几乎不产生收益的资产，予以加回，上限为经营现值的 20%（防止资产负债表数据异常主导估值）。

## 5. 离群值守卫与置信度

### 5.1 两级过滤（不再 fail-open）

1. **绝对合理性**：剔除 `< 0.2×现价` 或 `> 5×现价` 的值。区间故意放得很宽——这一级只抓**数据错误**（ADR 股数比例错、货币混淆），不做价值判断。
2. **稳健离散检验**：MAD（中位数绝对偏差）× 1.4826 作为标准差等价量，剔除偏离中位数 3.5 倍以上的值（模型数 ≥ 5 时启用）。
3. **保底**：若存活值少于 3 个，保留**离中位数最近的 3 个**——而不是回退到"用全部值"。

### 5.2 置信度与区间

输出新增 `valuation_quality` 字段：

- `dispersion` = `(P75 − P25) / 中位数`，衡量模型之间的**一致程度**
- `fair_value_low` / `fair_value_high` = 可靠模型值的 P25 / P75
- `confidence`：
  - `high`：≥5 年历史 且 ≥5 个模型入选 且 离散度 < 0.45
  - `low`：<3 年历史 或 <3 个模型入选 或 离散度 > 1.0
  - `medium`：其余

置信度衡量的是**模型之间是否互相认同**，不代表估值正确。页面文案已按此措辞。

### 5.3 前端透明化

`DCFDetailTable` 新增"估值输入归一化"面板，逐项展示：

- 每个输入的**报告值 vs 模型采用值**（FCF / EPS / 增长率 / 折现率）
- 历史波动系数
- 每一条调整的文字说明（例如："检测到资本开支高峰：当前 capex/营收 28.0%，历史中位数 12.0%"）
- 模型表新增**权重列**（按实际入选模型重新归一化，合计 100%）

## 8. 已知限制

- 归一化护栏（FCF `[0.75×, 2.5×]`、EPS `[0.7×, 2.0×]`）是**建模假设**，不是从数据推导出的参数。它们的作用是防止归一化把公司改写成另一家公司。
- 净现金加回的 20% 上限、EV/EBITDA 的 12× 乘数同属建模假设，均已在代码中命名为常量并注释。
- 制度转换的 0.8 / 1.25 阈值同上。
- Yahoo `fundamentalsTimeSeries` 对部分 ADR 与小市值标的的历史深度不足；不足 4 年时回退 FMP，仍不足则 `confidence` 降为 `low`。
- 本算法未做行业调整：EV/EBITDA 对全部行业使用同一个 12× 乘数。

| 股票 | 现价 | FWD P/E | PEG | DCF 均值 | 偏离 |
|---|---|---|---|---|---|
| AMZN | $256.78 | 24.7 | 1.50 | $108.07 | +137.6% |
| GOOGL | $338.50 | 22.8 | 1.21 | $142.39 | +137.7% |
| AAPL | $332.27 | 34.7 | 2.61 | $139.99 | +137.3% |
| MSFT | $495.63 | 21.0 | 1.61 | $190.42 | +160.3% |
| AVGO | $361.99 | 18.7 | 0.36 | $240.04 | +50.8% |
| TSM | $433.24 | 19.8 | 0.82 | $220.05 | +96.9% |

三家公司偏离度落在 137.3 / 137.6 / 137.7 的 0.4pp 区间内。财务结构差异极大的三家公司出现这种一致性，说明结果被某个结构性因素钉死，而非各自基本面。

## 10. 定量诊断

用具代表性的每股输入（由页面自身的 FWD P/E 与 PEG 反推）跑一遍加权流程：

```
加权结果 / 核心 DCF 锚 = 0.718 ~ 0.831
```

即**无论 DCF 算出什么，最终都被系统性砍掉 17–28%**。拖累来源：

| 模型 | 权重 | 相对现价 |
|---|---|---|
| 剩余收益 RIM | 9% | −69% ~ −72% |
| 格雷厄姆数字 | 2% | −68% ~ −78% |
| 盈利能力价值 EPV | 8% | −44% ~ −54% |
| 保守 FCF DCF（下行情景） | 11% | −55% ~ −62% |
| EV/EBITDA（写死 12×） | 11% | −20% ~ −60% |
| **合计** | **41%** | |

格雷厄姆公式则是不对称噪声：+65% / +103% / +159%，其中两个被离群过滤剔除、一个保留——同一模型在不同股票上时有时无。

## 11. 根本原因

**加权平均只在"估计同一个量"的估计值之间才有意义。**

原先的池子里混着两类完全不同的量：

| 类别 | 回答的问题 | 模型 |
|---|---|---|
| 持续经营内在价值 | 这门生意值多少 | 各期限 DCF、EV/EBITDA、第三方 DCF |
| 下限 / 零增长价值 | 增长停止时值多少 | EPV、剩余收益、格雷厄姆数字、保守下行 DCF |

把估值和下限平均，得到的既不是估值也不是下限——它对任何成长型企业施加了一道永久且不可见的折扣。这些下限模型本身没有错，它们只是在回答另一个问题。

## 12. v3 改动

### 12.1 三类角色（核心改动）

| 角色 | 作用 | 成员 |
|---|---|---|
| `value` | **决定公允价值** | 两阶段 DCF 34%、10年衰减 DCF 18%、EV/EBITDA 16%、5年 DCF 12%、第三方 DCF 14%、DDM 6% |
| `floor` | **单列为安全边际下限**（取中位数） | 保守下行 DCF、EPV、剩余收益 RIM、格雷厄姆数字 |
| `reference` | 仅展示，两者都不计入 | 格雷厄姆公式、Lynch PEG=1 |

格雷厄姆公式被划为 `reference` 的理由：`EPS × (8.5 + 2g)`，在 g=20 时等于给 48 倍市盈率——它不是一个有界估计，而 1962 年的筛选规则。Lynch 的 PEG=1 同理。

### 12.2 离群检验只在 `value` 组内进行

MAD（中位数绝对偏差）检验的前提是输入估计同一个量。跨异质模型运行时，它找到的不是坏数据，而是**最大的那个簇**，然后剔除其余——下限模型数量占优时，被剔除的恰恰是现金流模型。拆分后组内同质，MAD 才恢复其本意。

下限模型只做绝对合理性检查，不做离散度过滤——下限本来就该明显低于估值，因为"与估值不一致"而剔除它等于取消它的作用。

### 12.3 折现率不再由 FCF 波动率决定

**这是对 TSM 这类公司的关键修正。**

FCF 利润率的波动主要由**资本开支节奏**驱动，那是投资决策，不是经营风险。一家在建产能的公司 FCF 利润率剧烈波动；因此调高它的折现率等于对同一笔资本开支惩罚两次——一次体现在被压低的现金流里，再一次体现在折现率里——而且惩罚的恰恰是那些正在为未来增长买单的公司。

改为用**经营现金流利润率**与**净利率**的变异系数衡量风险（剥离了投资决策），FCF 波动率仍然展示但不计入定价。折现率下限同时从 8.5% 降到 8.0%（Morningstar 对 TSM 使用 8.2% WACC）；连续 7 年以上低波动的企业再降 50bp。

### 12.4 增长率：前瞻与历史分组等权，不再由数量决定

v2 取 6 个来源的中位数看似稳健，实则不然：历史 CAGR 类来源有 4 个、前瞻类只有 1–2 个，中位数**永远落在后视镜那一侧**，前瞻视角完全无法影响结果。对处在拐点的公司（产能周期完成、新产品周期启动），这等于硬编码"未来十年等于过去十年"。

改为：

```
历史组（营收/净利/FCF CAGR、最近一期同比）→ 组内取中位数
前瞻组（分析师长期增速预期）           → 组内取中位数
最终 = 两组各 50%
```

组内中位数保留了 v2 的核心保护（一个畸形季度仍被同组其他来源压过，META 场景不受影响），组间等权则使前瞻视角不因历史序列数量多而被淹没。增长率上限从 25% 放宽到 30%。

### 12.5 EV/EBITDA 乘数改用该公司自身历史中位数

写死 12× 不是中性的——它对任何市场长期给予更高乘数的公司构成 40–50% 的隐性折扣。

改为取该公司自身近十年 **EV/EBITDA 中位数**（FMP enterprise-values 拉 10 年，与年报 EBITDA 按财年匹配），打 9 折后使用，限制在 [5×, 25×]。这是**观测值**而非假设。无法计算时退回按增长率推算的乘数 `8 + 40g`，限制在 [6×, 20×]。

用历史中位数而非当期乘数，避免了循环论证（当期乘数会直接还原出今天的股价）。

## 17. AMZN / GOOGL 塌陷的机制

v3 的 `value` 组里，除 EV/EBITDA 外的全部内部模型都有同一个前置条件：

```ts
if (hasFcf && hasShares && growthRate != null) { ... }
```

自由现金流不可用时（重资本开支期 FCF 接近零或为负），这些模型全部跳过。

v2 里这不致命——EPS 类模型（EPV、剩余收益、格雷厄姆数字）在同一个池子里兜底。**v3 把它们全部划为 `floor`**，于是一旦 FCF 不可用，`value` 组只剩第三方 FMP DCF，公允价值就变成"某个数据商的 DCF 端点说了算"。FMP 的 DCF 对现金流形态特殊的公司有已知的失效模式：返回接近零的值。

更糟的是离群守卫的兜底分支：

```ts
// v3：少于 3 个存活时，保留"离全部值中位数最近的 3 个"
```

这会**复活刚刚被绝对合理性检验判定为坏数据的值**。$17.68 低于 `0.2 × 现价 = $50.69`，本应被剔除，却被兜底分支救了回来。

## 18. 公开模型的方法论（按用户要求调研）

[Simply Wall St 的模型规格是公开的](https://github.com/SimplyWallSt/Company-Analysis-Model/blob/master/MODEL.markdown)：

| 项 | Simply Wall St | v3 | 差距 |
|---|---|---|---|
| 现金流口径 | 杠杆后 FCFE | 杠杆后 FCF | 一致 |
| 明确预测期 | **10 年分析师 FCFE 预估** | 5年增长 + 5年衰减 | 中 |
| 增长来源 | **分析师共识为主**，历史 CAGR 仅回退 | 历史/前瞻 50:50 | 大 |
| 折现率 | **CAPM**：Rf + 杠杆Beta（限 0.8–2.0）× ERP（Damodaran） | 9% 基准 + 波动调整 | 大 |
| 无风险利率 | 10年期国债 **5 年均值** | 不使用 | — |
| **永续增长率** | **10年期国债收益率** | **固定 2.5%** | **极大** |

### 永续增长率是单项影响最大的参数

终值占 DCF 现值的 60–70%，而终值倍数 = 1/(r − g)：

| r | g | 终值倍数 |
|---|---|---|
| 9.0% | 2.5%（v3） | 15.4× |
| 9.0% | 3.0%（v4） | 16.7× |
| 9.0% | 4.0%（SWS 惯例） | 20.0× |

Damodaran 的规则：**终值增长率不得超过无风险利率**——因为无风险利率是长期名义 GDP 增长的代理，增长永远快于经济意味着最终变成整个经济。在 10 年期约 4% 时用固定 2.5%，不是"中性"，是对每一个终值的永久折扣。

v4 取 `min(无风险利率, 3.0%)`：无风险利率是上限（Damodaran），3.0% 是工作上限——永续保持完整名义 GDP 增速意味着永远不向新进入者让出一分市场份额。取 3.0% 而非完整的 4.0%，是有意留在保守一侧。

## 19. v4 改动

### 19.1 新增盈利折现 DCF（修复塌陷）

与现金流模型**同结构**，以归一化 EPS 作为现金代理，权重 12%，角色 `value`。只要公司盈利为正就可用，所以 `value` 组不可能再塌陷到只剩第三方 DCF。

EPS 是比 FCF 更弱的所有者现金代理（忽略营运资本、不资本化任何东西），所以权重低于现金流模型，且现金流模型可用时它不是锚。

### 19.2 第三方 DCF 隔离

- 合计权重上限 **20%**
- **没有任何内部模型存活时，第三方 DCF 完全不使用**——宁可没有公允价值，也不要一个错的
- 离群守卫兜底分支只在**通过绝对合理性检验的值**之间挑选，不再复活坏数据

### 19.3 折现率改为 CAPM

```
股权成本 = 无风险利率(10年期国债) + Beta(限 0.8–2.0) × 股权风险溢价(4.5%)
         + 经营波动微调（-50bp ~ +150bp，非对称）
限制区间 [8.0%, 14.0%]
```

固定 9% 基准同时忽略了利率水平和个股风险。微调设为非对称，是为了让 CAPM 成为下限而非可侵蚀的起点。8% 下限防止坏 Beta 或坏利率读数传导。

### 19.4 PEG 隐含增速进入前瞻组

`PEG = 前瞻PE / 增长率%`，所以 `前瞻PE ÷ PEG` 反解出 PEG 本身编码的增长率。

这是让 **PEG 列和公允价值列指向同一方向**的关键。两者是同一家公司的两个视角；当 DCF 使用 PEG 从未见过的增长假设时，页面会同时显示"PEG 0.36，便宜"和"公允价值低于现价 30%"——这不是细致的观点，是内部矛盾。

把隐含增速作为前瞻组的一票，从源头消除矛盾，同时**保留两者合理分歧的空间**：DCF 扣资本开支和定价风险，PEG 两者都不做。

### 19.5 PEG / DCF 方向矛盾诊断

PEG < 1（便宜）而 DCF 显示高估 >15%（或反向）时，`valuation_quality.peg_conflict` 给出提示并指出最可能的原因——资本密集度超过营收 12% 时直接点名，否则指向增长假设明细。前端以警示条展示。

### 19.6 终值占比守卫

终值占现值 >85% 时，估值实质上是"对外推的外推"，置信度不得为 `high`。前端展示该比例。
